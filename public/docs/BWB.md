## How we write options on invoices

| Option | Value | Printed on invoice as |
|---|---|---|
| mount | Inside mount (`inside`) | `IM`, `inside` |
| mount | Outside mount (`outside`) | `OM`, `outside` |
| lift | Cordless (`cordless`) | `CRDLS`, `cordless` |
| lift | Continuous loop (`continuous_loop`) | `CONT LOOP`, `loop` |
| lift | Motorized (`motorized`) | `PWR`, `motor`, `motorized` |
| control side | Left (`left`) | `LH`, `left` |
| control side | Right (`right`) | `RH`, `right` |
| valance | Standard valance (`standard_valance`) | `STD VAL`, `standard valance` |
| valance | Crown valance (`crown_valance`) | `CRN VAL`, `crown` |

Sizes are width × height in inches, to the nearest 1/8". Every line is one window (qty 1).
