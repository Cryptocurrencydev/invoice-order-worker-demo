## How we write options on invoices

| Option | Value | Printed on invoice as |
|---|---|---|
| mount | Inside mount (`inside`) | `INS`, `inside` |
| mount | Outside mount (`outside`) | `OUT`, `outside` |
| lift | Cordless (`cordless`) | `CL`, `cordless` |
| lift | Continuous loop (`continuous_loop`) | `CLP`, `loop` |
| lift | Motorized (`motorized`) | `MTR`, `motor`, `motorized` |
| control side | Left (`left`) | `L`, `left` |
| control side | Right (`right`) | `R`, `right` |
| valance | Cassette valance (`cassette`) | `CAS`, `cassette` |
| valance | Fascia (`fascia`) | `FAS`, `fascia` |

Sizes are width × height in inches, to the nearest 1/8". Every line is one window (qty 1).

| Remote | Description |
|---|---|

Motorized lines must specify a motor and a compatible remote or hub.
