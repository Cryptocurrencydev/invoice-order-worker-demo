## How we write options on invoices

| Option | Value | Printed on invoice as |
|---|---|---|
| mount | Inside mount (`inside`) | `Inside Mount`, `inside` |
| mount | Outside mount (`outside`) | `Outside Mount`, `outside` |
| lift | Cordless (`cordless`) | `Cordless` |
| lift | Continuous loop (`continuous_loop`) | `Continuous Loop`, `loop` |
| lift | Motorized (`motorized`) | `Motorized`, `motor` |
| control side | Left (`left`) | `Left` |
| control side | Right (`right`) | `Right` |
| valance | Cassette valance (`cassette`) | `Cassette` |
| valance | Fascia (`fascia`) | `Fascia` |

Sizes are width × height in inches, to the nearest 1/8". Every line is one window (qty 1).

## Motors and remotes

| Motor | Description | Compatible remotes |
|---|---|---|
| LM-Q | Lumaris Quiet shade motor | LR-1, LR-15 |
| LM-T | Lumaris drapery track motor | LR-15, LH-BRIDGE |

| Remote | Description |
|---|---|
| LR-1 | 1-channel remote |
| LR-15 | 15-channel remote |
| LH-BRIDGE | Lumaris bridge (app + voice) |

Motorized lines must specify a motor and a compatible remote or hub.
